# MDiary v2.7.0 发布说明（Windows x64）

发布日期：2026-11-10　｜　版本：`2.7.0+13`　｜　基于 v2.6.0

## 1. 统一模型管理

设置 → **模型**：

- 配置（profile）：名称、提供商（本地 Ollama / 云端 OpenAI 兼容）、地址、模型名、Key；
- 角色（role）：问答对话、摘要/日报/soul、分词切分、记忆对话、向量索引；
- 一套配置可被多个角色复用；未设置的角色回退到旧「RAG 模型」设置；
- 首次启动自动从旧 `settings.json` 迁移，写 `<数据目录>/models.json`；
- 云端 Key 仍用 Windows DPAPI 加密；向量角色只支持本地。

## 2. 分词导入

导航栏「分词导入」：

1. 选文件夹（`.md` / `.txt`，递归，单文件 ≤ 2 MB）；
2. 用 `segment` 角色模型切分（只依赖材料，按日期合并）；
3. 预览每天：标题、字数、标签、附件，以及警告（缺日期、重复、未知附件）；
4. 确认后自动新建库 `<数据目录>/libraries/<文件夹名>/`，写入日期文件夹并导入，切换过去。

## 3. 记忆对话

导航栏「记忆对话」：

- 只使用**蒸馏 skill**（最新一份）作为人设与知识来源，不检索日记；
- 最近 20 条对话 + skill 全文 + 当前问题发给 `memory` 角色模型；
- 按库持久化到 `<库目录>/agent/chat.jsonl`；「新对话」清空当前库记录；
- 没有 skill 时明确提示先去蒸馏。

## 4. 其他

- 编辑器底部字数/保存时间加了 Tooltip 说明；
- 修正 skill 目录多一层 `db` 的问题（现在固定在 `<库目录>/skill/`）。

## 5. 验证

- `flutter analyze` 0 issue；`flutter test` **279 passed**（新增 5 + 6）；
- release 构建与冒烟通过；
- 新增文档：`docs/models.md`、`docs/segmenter.md`、`docs/memory.md`。

## 6. 已知限制

- 旧「RAG 模型」卡片仍保留（云端开关/Key/蒸馏），与「模型」区有重叠，下一步收拢；
- 分词只支持 md/txt，60k 字符后截断；
- 记忆对话无流式、只取最近 20 条；
- 分词预览不能逐条编辑。
