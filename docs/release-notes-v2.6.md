# MDiary v2.6.0 发布说明（Windows x64）

发布日期：2026-11-10　｜　版本：`2.6.0+12`　｜　基于 v2.5.1

## 1. 星图重做：星座 → 星云 → 星系

按选定的 **A+B** 方案实现，一套数据、四个尺度：

| 尺度 | 画面 |
|---|---|
| 周 | 7 个槽位，每天一颗星连成星座；空白日只留暗点 |
| 月 | 当月每天一颗星，按椭圆星座排布；附件绕所属日记星公转 |
| 年 | 12 个月的星团连成环，每团里有当月所有日记 |
| 全部 | 每年一团星云，按时间螺旋排开，组成星系 |

交互：

- **滚轮**缩放：全部 ↔ 年 ↔ 月 ↔ 周，顶部按钮等价；
- **拖拽**平移；右上角「复位」；
- **点星**回主界面并打开那篇日记；
- 标签筛选保留。

动画：

- 星呼吸（12 s 循环、错峰）；
- 附件沿椭圆轨道公转；
- 星云粒子缓慢漂移（确定性种子）；
- 星团 / 星云有径向光晕。

## 2. 实现

| 文件 | 作用 |
|---|---|
| `lib/features/star_map/cosmos_layout.dart` | 纯几何：按日期算星位、连线、轨道、星团；确定性（同一天位置稳定） |
| `lib/features/star_map/cosmos_painter.dart` | `CustomPainter`：背景星、星云、连线、轨道、星与文字 |
| `lib/features/star_map/star_map_page.dart` | 尺度切换、滚轮、拖拽、命中、复位 |

- 单测 6 例：周槽位/连线/轨道、月天数、年 12 团、全部按年、位置稳定、命中；

- 测试里可关闭循环动画（`StarMapPage.disableAnimations`），避免测试不收敛。

## 4. 已知限制

- 年 / 全部尺度不画附件轨道（避免过密）；
- 尺度切换是重建 + 淡入，不是同一批星的位置插值（连续形变留后续）；
- 全部视图年份多时星云半径变大，需要手动缩放；
- 极老机器上粒子多时可能掉帧，暂未做自动降采样。
