# 记忆对话（v2.7 第三步）

> 只用**蒸馏 skill** 作为人设与知识来源，不检索日记；对话按库持久化。

## 入口

导航栏「记忆对话」，与「分词导入」「星图」「RAG」「蒸馏」并列。

## 流程

1. 先在「蒸馏」页生成至少一份 skill（最新的一份生效）；
2. 打开记忆对话，输入问题；
3. `memory` 角色模型收到提示词：skill 全文 + 最近 20 条对话 + 当前问题；
4. 回答流式/一次性写回（当前实现为一次性返回）；
5. 对话存到 `<库目录>/agent/chat.jsonl`，一行一条，换库各自独立；
6. 「新对话」清空当前库的聊天记录（skill 不受影响）。

## 提示词规则

- skill 是唯一事实来源；skill 里没有就说「skill 里没有提到」；
- 第一人称、口语化、≤ 200 字；
- 允许追问，不主动索取隐私。

## 存储

```
<库目录>/
  agent/
    chat.jsonl    # {"from_user":true,"text":"...","at":"..."}
```

放在库目录里，整库复制/备份时聊天记录一起走；不想带就删 `agent/`。

## 模型

设置 → 模型 → 记忆对话角色。未设置时回退到旧「生成模型」。

## 限制

- 只用 skill，**不会**去检索日记原文（这是用户明确选择的模式）；
- 无流式输出，等待时只有「思考中」；
- 历史只取最近 20 条，长对话早期信息会丢；
- skill 更新后，旧对话不会自动重写。
