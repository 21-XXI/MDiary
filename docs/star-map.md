# 星图（v2.6）

> 星座 → 星云 → 星系 的连续缩放。A+B 方案，不引第三方图库（`CustomPainter` + `AnimationController`）。

## 尺度

| 尺度 | 画什么 | 交互 |
|---|---|---|
| 周 | 7 个槽位（每天一颗星），连成星座；有日记的星亮、空白日暗点 | 悬停/点击星打开当天 |
| 月 | 当月每天一颗星，按椭圆星座排布；只连有日记的相邻天 | 同上 |
| 年 | 12 个月各一个星团（含当月所有星），星团之间连成环 | 点星打开，星团显示月份 |
| 全部 | 每年一团星云，按时间螺旋排开 | 点星打开，星团显示年份 |

- 缩放：**滚轮**上滚放大（全部→年→月→周），下滚缩小；顶部「周/月/年/全部」按钮等价；
- 平移：拖拽；
- 复位：右上角「复位」按钮；
- 点星：返回主界面并打开那篇日记；
- 附件：周/月视图里，附件绕所属日记星旋转（每颗 8–12 s 一圈的效果由全局 phase 驱动）。

## 视觉与动画

| 元素 | 效果 |
|---|---|
| 背景 | 径向深空渐变 + 150 颗环境星 |
| 星 | 呼吸（12 s 循环，错峰），外发光 |
| 连线 | 星座连线，透明度按"两端是否都有日记"变化 |
| 星云 | 年/全部视图：径向渐变 + 每团 110 个粒子（按 seed 确定性生成） |
| 附件 | 椭圆轨道 + 沿轨道运动的点 |
| 文字 | 周/月显示星期/日期，年显示月份，全部显示年份 |

## 数据与性能

- 布局纯函数 `buildCosmosLayout(entries, attachments, period, size)`，不碰 IO，单测覆盖；
- 位置由日期决定（无随机抖动），同一天每次进入位置一致；
- 粒子总数：年视图 12×110 ≈ 1320，全部视图按年数 ×110，上限随年份增长；
- 每帧只重绘 `CustomPaint`（`AnimatedBuilder` 包住 painter），不重建页面；
- 测试里 `StarMapPage.disableAnimations = true` 停掉循环动画，避免 `pumpAndSettle` 不收敛。

## 已知限制

- 年/全部视图不画附件轨道（星太多，避免糊成一片）；
- 全部视图的星云按年份螺旋排列，年份很多时半径会变大，需要手动缩放；
- 星云粒子是确定性伪随机，不同机器一致，但不是真实数据分布；
- 没有真正的"连续形变"——切换尺度是淡入淡出的重建，不是同一批星插值（连续插值留到后续）。
