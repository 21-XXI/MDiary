# MDiary v2.8.0 发布说明（Windows x64）

发布日期：2026-11-10　｜　版本：`2.8.0+15`　｜　基于 v2.7.1

## 1. 导航与 RAG
- 导航栏收成 4 个常用 + 「更多」菜单（分词 / 蒸馏 / Agent / 回收站）；
- 问答回答里的 `[日期-标题]` 可点击，直接打开日记或附件。

## 2. 蒸馏
- 改为「生成预览 → 确认保存」，不确认不落盘。

## 3. Markdown 编辑器
- 语法高亮、行号 + 当前行高亮；
- 自动配对括号、回车续列表、Tab/Shift+Tab 缩进；
- Ctrl+F 查找替换（大小写/正则）、大纲、Ctrl+P 命令面板（插入表格/公式/Mermaid）。

## 4. 一天一个主文件 + 附加 md
- 「新建日记」当天已有主文件时直接打开（Ctrl+N 仍可强制新建）；
- 工具栏「附加 md 笔记」：作为附件保存并链接到主文件；
- 点击 `.md` 附件可在应用内编辑，保存后自动替换引用；
- 附加 md 保存后会触发 RAG 重建索引，可被问答检索到。

## 5. 验证
- `flutter analyze` 0 issue；`flutter test` 293 passed；
- 手动清单 `docs/manual-test-v2.8.md`；审查报告见 `docs/reviews/`。

## 6. 已知限制
- 附加笔记不计入当天字数；编辑产生的旧 blob 可能残留；
- 行号与软换行对齐不完美；高亮是正则级；
- 索引触发是整库增量重建，大库保存附加笔记会有短暂延迟。
