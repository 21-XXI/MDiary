## 2. 原因

- 2.0 的问答是「一问一答」，实际使用常要追问（「那晚饭呢？」），每次都重建上下文很别扭；
- 索引是否就绪、这次回答是否走了云端，界面上看不见，用户不知道「为什么答不出来」；
- 模型下拉只有检测到的模型，想先填名字再拉模型时没法输入。

## 3. 风险

| 级别 | 项 | 说明 |
|---|---|---|
| 低 | 上下文截断 | 只保留 3 轮、每条 200 字，长会话早期信息会丢；这是刻意的成本控制 |
| 低 | 自定义模型名写错 | 只报「是否已拉取」，不自动回退；避免悄悄换模型 |
| 低 | 进度条精度 | 依赖逐条 embedding 回调，总数包含附件；超大库首次重建仍慢 |
| 低 | 标注可能误导 | 「本地/云端」按当前设置显示；若生成中途切换设置，标注不会实时变（下一条才变） |
