## 2. 设计决定

- **只用 skill**（用户选择）：不检索日记，避免"记忆"变成第三个 RAG；
- **skill 取最新一份**：与蒸馏页列表一致；
- **JSONL 放库内**：`<库>/agent/chat.jsonl`，换库独立、备份一起走、可直接删除；
- **无流式**：`completeForRole` 一次性返回，UI 用「思考中」占位；流式留后续；
- **不改数据库 schema**：避免迁移风险。

## 3. 风险与遗留

| 级别 | 项 | 说明 |
|---|---|---|
| 中 | 无流式 | 长回答等待感明显 |
| 中 | 只取最近 20 条 | 长对话早期信息丢 |
| 中 | skill 更新不重写历史 | 旧对话仍按旧 skill 记录 |
| 低 | JSONL 无锁 | 单进程使用；并发写不在支持范围 |
| 低 | 旧 skill 目录迁移 | v2.2 可能写在 `db/db/skill`，本次修正后旧目录不会被自动搬 |
