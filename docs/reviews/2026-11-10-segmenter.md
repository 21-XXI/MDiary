## 2. 设计决定

- **先预览再建库**：模型失败不会留下半成品库；
- **复用现有导入管线**：把结果写成 `日期/当期.md` + 附件，交给 `MarkdownIo.importDirectory`，附件自动内容寻址；
- **新库固定放 `libraries/<文件夹名>`**，重名加 `(2)`，导入后自动切换；
- **按角色取模型**（`segment`），未配置时回退旧生成模型；
- 预览只做整体确认，暂不支持逐条编辑，避免第一版状态太复杂。

## 3. 风险与遗留

| 级别 | 项 | 说明 |
|---|---|---|
| 中 | 长材料截断 | 60k 字符后不再送入模型，可能漏掉后半段的日期 |
| 中 | 附件同名冲突 | 按 basename 在源目录递归找，同名不同目录会取第一个 |
| 中 | 模型漏日期 | 本地 8B 在长材料上表现一般；建议 `segment` 角色配云端或更大模型 |
| 低 | 只支持 md/txt | PDF/Word 需要解析库，未做 |
| 低 | 预览不可编辑 | 只能整体确认/重来 |
| 低 | 建库后立即切换 | 用户想先检查需手动切回 |
