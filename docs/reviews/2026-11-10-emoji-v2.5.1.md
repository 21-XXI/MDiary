## 2. 设计决定

- **源码里存短代码**（`:smile:`），不是直接存 emoji：可读、可替换、可回退；
- 内置表放代码里，用户映射只存增量到 meta（JSON），换库不丢、不联网；
- 自定义优先于内置；删除自定义即恢复内置值（"可替代"）；
- 只在预览层替换，**不改数据库正文**；导出 `.md` 仍是短代码；
- 跳过代码块与行内代码，避免把示例代码改坏。

## 3. 风险与遗留

| 级别 | 项 | 说明 |
|---|---|---|
| 低 | 正文里合法的 `:xx:` | 例如时间 `:30:` 不匹配（无对应短代码），会原样保留 |
| 低 | 短代码冲突 | 自定义可覆盖内置；删除后恢复，不会丢数据 |
| 低 | 表情显示 | 依赖系统 emoji 字体（Windows 10/11 自带 Segoe UI Emoji） |
| 中 | 只支持字符表情 | 图片/GIF 表情包未做，映射值目前是字符串；后续可扩成 `assets/...` |
| 低 | 中文短代码 | 允许 CJK，但搜索按子串匹配，短代码过长会影响可读性 |
