## 2. 审查发现（开发中实际踩到并修掉的）

| # | 问题 | 现象 | 修法 |
|---|---|---|---|
| 1 | DPAPI 找错 DLL | `protect` 静默降级成 base64，测试断言失败 | CryptProtectData 在 **crypt32.dll**，不是 advapi32 |
| 2 | HttpClient 默认 latin1 | 中文提示词写入抛 `Contains invalid characters` | 显式 `contentType = application/json; charset=utf-8` |
| 3 | qwen3 思考模式 | 问答 27.5 s 且把有依据的问题答成「没有提到」 | 请求带 `think:false`，实测 9 s 答对 |
| 4 | 导航栏多一个图标 | 800×600 下头部 `RenderFlex overflowed` | 头部 `Row + Spacer` 改 `Wrap` |
| 5 | 设置页变长 | 「整库导出」在 1600 高视口外，点击命中失败 | 测试先 `ensureVisible` |
| 6 | 星图自动缩放 | 自动 fit 后点击坐标漂移，星图用例失败 | 取消自动 fit，保留「适应窗口」按钮 |
| 7 | SSE 测试服务端编码 | 服务端默认 latin1，中文字段导致客户端挂起 | 测试服务端也使用 utf-8 |

## 3. 风险与遗留

| 级别 | 项 | 说明 / 后续 |
|---|---|---|
| 中 | 向量检索为纯 Dart 暴力扫描 | 单库 > 5 万切片会慢；`docs/rag.md` 已记录，后续可换 sqlite-vec |
| 中 | 模型质量依赖本机 | qwen3:8b 在 6 GB 卡上 10.5 tok/s、30% CPU 卸载；已给调优建议（4B/num_ctx/num_predict） |
| 中 | 云端只覆盖问答/生成 | embedding 始终本地（有意为之），已在文档与 UI 说明 |
| 低 | 日报补全文件多 | 空日也写，首次可能几百个小文件；已限制 366 天 |
| 低 | 摘要只到条目级 | chunk 级摘要未做，检索仍用原文 |
| 低 | 非 Windows Key 保护 | 退化为 base64 并在 UI 提示，等 macOS/Linux 迁移时再补 |
| 低 | 启动后台任务不可见 | 2.0.7 前无进度；2.1 起问答页可见索引状态，后台任务仍只写日志 |
