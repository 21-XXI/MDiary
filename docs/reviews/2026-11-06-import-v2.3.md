## 2. 设计决定

- **文件夹日期优先于 mtime**：`父文件夹/日期/` 是用户显式表达，不应被文件拷贝时间覆盖；
- **只在日期文件夹里自动收附件**：普通目录继续"只导入引用附件"，避免误收一堆无关文件；
- 追加的附件引用放在正文末尾的 `## 附件`，不打断原有正文；
- 已引用文件按文件名去重，避免同一张图既在正文又在列表里；
- 分词器 skill 同时提供「模型直接写文件」与「JSON + 脚本落盘」两条路，适配不同 agent 能力。

## 3. 风险与遗留

| 级别 | 项 | 说明 |
|---|---|---|
| 中 | 同日多 .md | 日期文件夹里若有多篇 .md，每篇都会各自导入整目录附件，可能重复；约定一个日期一个 `当期.md` |
| 中 | 附件体积 | 目录里的所有非 md 文件都会尝试导入，大文件受 100 MB 上限约束并记入 errors |
| 低 | 日期格式 | 只认常见格式；`2026年11月6日-第二天` 这类会取到第一段日期，符合预期 |
| 低 | 重复导入 | 去重按「日期 + 正文」，追加附件后的正文与首次不同，重导会跳过（先于追加判断） |
| 低 | skill 未接入 App | `skills/` 是交付物，不在应用内加载；后续可考虑内置 skill 管理页 |
