# 提交审查记录 — 2026-11-10 无 skill 的记忆对话回退

**范围**：没有蒸馏 skill（或被切走）时，记忆对话退回普通模型对话，不报错、不检索日记
**对应需求**：用户「记忆对话时没有 skill 或切换 skill 到没有时，正常和模型对话，暂不检索 RAG」

## 改动
- `buildMemoryPrompt`：skill 为空时走「普通对话」提示词（不假装记得日记，不编造细节）；
- `AppState.askMemory`：去掉「没有 skill 抛异常」，改用空 skill 提示词；
- 运行日志摘要标注「普通对话（无 skill）」；
- 记忆页顶部提示改为「未配置 skill：进行普通对话（不检索日记）」。

## 风险
- 普通对话仍走 `memory` 角色模型；未配置时回退旧生成模型；
- 没有 skill 时不检索日记（符合当前选择），用户问具体细节会得到「无法回忆」；
- 旧对话记录不受影响。
