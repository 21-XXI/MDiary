## 3. 风险与遗留

| 级别 | 项 | 说明 |
|---|---|---|
| 中 | Mermaid 仅源码 | 用户需复制到 mermaid.live 才能看图；离线不可视 |
| 中 | 块级公式渲染成本 | 每个公式构建一棵 TeX 组件树，长文大量公式会变慢；暂未做缓存 |
| 中 | 公式错误回退 | 仅捕获 parse error，极端 TeX 可能抛别的异常（已用 onErrorFallback 包裹构建） |
| 低 | `$` 误判 | 行内正则要求成对且非空；货币 `$5` 不受影响，但 `$5 和 $6` 可能被当成公式 |
| 低 | 字体跨机 | 依赖系统已安装字体，未安装时回落到默认 |
| 低 | 语言缺失 | 用户明确要求的语言设置本版未交付，需下一版补齐 |
