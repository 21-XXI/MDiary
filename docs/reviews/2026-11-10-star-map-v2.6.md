## 2. 设计决定

- **一套布局、四个尺度**：周 7 槽、月按天数、年 12 团、全部按年螺旋；切换只重建，不换页面；
- **位置确定性**：日期 → 角度/半径，无随机；同一天每次进入位置一致，可测试；
- **附件公转只在周/月**：年/全部星太多，避免糊成一片（LOD）；
- **单个 Ticker** 驱动 phase，`AnimatedBuilder` 只重建 painter，不重建页面；
- **测试开关** `StarMapPage.disableAnimations`：循环动画会让 `pumpAndSettle` 永远不收敛。

## 3. 风险与遗留

| 级别 | 项 | 说明 |
|---|---|---|
| 中 | 尺度切换不是形变 | 目前是重建 + 立即重绘，没有 A 的星收缩成 B 星云的连续插值；视觉上偏"切页" |
| 中 | 粒子性能 | 年 12×110 + 全部按年数×110；老机器可能掉帧，未做自动降采样 |
| 低 | 年/全部无附件 | 附件只在周/月显示，是刻意的 LOD |
| 低 | 点击热区 | 命中半径 20px，星密集时优先最近；年/全部星很小，点中靠半径补偿 |
| 低 | 标签筛选 | 只过滤日记，不重算布局（空出来的位置仍是暗点） |
| 低 | 双击复位移除 | 与单击冲突（双击识别器会延迟单击），改为右上角「复位」按钮 |
