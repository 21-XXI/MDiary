# 提交审查记录 — 2026-11-10 一天一个主文件 + 附加 md 笔记

**范围**：新建入口按天去重；附加 .md 笔记（可编辑、链接回主文件）
**对应需求**：用户「一天只能有一个 .md，长文本用附加 .md 附件链接到主文件，并且能继续编辑」

## 改动
- `attachment_repository.dart`：`updateContent`（更新 sha/大小/mime）。
- `app_state.dart`：`attachmentText`（读 blob）、`saveMarkdownNote`（新建/更新附件、写链接、替换旧 sha 引用）。
- `entry_editor_page.dart`：工具栏「附加 md 笔记」；附件条里 .md 附件点击改为应用内编辑；保存后刷新正文与附件。
- `home_page.dart`：两个「新建日记」按钮走 `_newEntry`，当天已有主文件时直接打开（Ctrl+N 仍可强制新建）。
- `test/note_attachment_test.dart`（2 例）；空草稿用例改为 API 造第二篇。

## 风险
- 附加笔记不参与 RAG 索引；
- 编辑生成新 blob，旧 blob 可能成为孤儿（清理需手动/后续任务）；
- Ctrl+N 仍能建第二篇（保留快捷方式，未强制）；
- 附加笔记的字数不计入当天统计。
