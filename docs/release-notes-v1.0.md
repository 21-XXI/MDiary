# MDiary v1.0.0 发布说明（Windows x64）

发布日期：2026-11-02 ｜ 版本：`1.0.0+1` ｜ 目标平台：Windows 10 1809+ / 11 x64

## 1. 交付物

| 文件 | 说明 |
|---|---|
| `MDiary-1.0.0-windows-x64.zip` | 可执行包，解压即用（无需安装、不写注册表） |
| `mdiary.exe` | 程序入口（同级需要 `data/`、`flutter_windows.dll`、`sqlite3.dll`） |
| `data/app.so` | Dart AOT 快照（业务代码都在这里） |
| `使用说明.md` | 面向使用者的操作与备份说明 |
| `验收清单.md` | A–F 组验收表，A 组已回填自动验证结果 |

**校验值**：见压缩包同级的 `SHA256SUMS.txt`（在命令行执行
`certutil -hashfile MDiary-1.0.0-windows-x64.zip SHA256` 可与其中数值比对）。
校验值不写进本文件，否则「改说明 → 重新打包 → 校验值变化」会自相矛盾。

## 2. 功能范围（对应 project.md 目标 1–4）

| 目标 | 实现 |
|---|---|
| 目标 1 书写并保存 .md | Markdown 编辑（编辑/分栏/预览）、800ms 防抖自动保存、Ctrl+S 立即保存、单篇导出、整库导出（`日期-标题.md` + `assets/`） |
| 目标 2 本地存储 | SQLite（WAL）为唯一真源，`PRAGMA user_version` 迁移；附件二进制不入库 |
| 目标 3 可查看 | 时间轴分组列表、置顶、中文子串搜索（24 篇/千篇实测 3–37ms）、回收站恢复 |
| 目标 4 附件 | 任意文件（≤ 25 MB）、sha256 内容寻址去重、图片内嵌预览、其他文件系统默认程序打开、GC 回收孤儿文件 |

工程指标：代码 3,090 行（lib）+ 1,072 行（test）；56 个自动化测试；`flutter analyze` 0 issue。

## 3. 已知限制（v1.0 明确不做）

1. **附件插入方式**：菜单选择与 Windows 拖拽已支持；**剪贴板粘贴截图未实现**（需读 CF_DIB 后编码 PNG，列 v1.1）。
2. **搜索为 `LIKE` 子串匹配**，未上 FTS5；千篇实测 37ms，暂不构成瓶颈。搜索范围含标题、正文、标签名。
3. **无工作区（Vault）模式**：数据默认在 `<exe 目录>\MDiaryData`（绿色版），设置页可换目录并迁移；`MDIARY_HOME` 可覆盖。导出即得到标准 Markdown 目录。
4. **无账号/同步/加密**：v3.0 才接 Go + PostgreSQL；同步字段（`rev`/`device_id`/`deleted_at`）已预留。
5. **未做代码签名**：首次运行可能有 SmartScreen 提示。
6. **单实例未加锁**：同时开两个实例会共享同一数据库文件（WAL 允许，但不建议同时编辑同一篇）。
