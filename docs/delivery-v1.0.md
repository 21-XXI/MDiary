# MDiary v1.0.0 交付说明（Windows x64）

> 这是给验收者的封面页。功能细节看 `使用说明.md`，逐条打勾用 `验收清单.md`，
> 设计取舍看 `发布说明.md`。

## 1. 怎么开始（3 步）

1. 解压 `MDiary-1.0.0-windows-x64.zip` 到任意英文或中文目录（**整个目录一起放**，不要只拷 exe）。
2. 双击 `mdiary.exe`。若被 SmartScreen 拦截：更多信息 → 仍要运行（未做代码签名）。
3. 按 `验收清单.md` 从 B 组开始点，重点先跑这 5 条：

| 顺序 | 操作 | 期望 |
|---|---|---|
| 1 | 新建 → 输入中文 + 英文 + 表情 → 停 1 秒 | 右上显示「已保存」 |
| 2 | 直接点 × 关窗 → 重新打开 | 内容完整（含关窗前的最后输入） |
| 3 | 回形针插入一张图片 → 切「分栏」 | 图片在预览中显示 |
| 4 | 导出一篇 .md → 用 Typora/VS Code 打开 | 排版正常、无多余反斜杠 |
| 5 | 把窗口拖到很小再拖回 | 按钮不消失、文字不被切 |

## 2. 校验值

```
MDiary-1.0.0-windows-x64.zip
  sha256  <见同级 SHA256SUMS.txt>
  核对    certutil -hashfile MDiary-1.0.0-windows-x64.zip SHA256
```

`SHA256SUMS.txt` 与 zip 放在同一目录，请以它为准（重新打包会变）。

## 3. 数据在哪

| 内容 | 路径 |
|---|---|
| 数据库 | `%APPDATA%\MDiary\mdiary.sqlite` |
| 附件 | `%APPDATA%\MDiary\attachments\` |
| 错误日志 | `%APPDATA%\MDiary\logs\error.log`（发生异常时才出现） |

想放到别的盘 / U 盘便携使用：命令行 `set MDIARY_HOME=D:\我的日记 && mdiary.exe`。
**备份**：关闭程序后复制整个 `%APPDATA%\MDiary`；或用设置页「整库导出」得到纯 Markdown。

## 4. 遇到问题怎么反馈

请提供三样：

1. 验收清单编号（如 `E1`、`D7`）+ 期望与实际现象；
2. 复现步骤（点哪里、输入什么）；
3. 如果闪退/白屏，附 `%APPDATA%\MDiary\logs\error.log`。

我会按 Git 提交规范逐条修，每次修复都带 diff 审查意见。

## 5. 这一版的质量基线

| 项 | 数值 |
|---|---|
| 自动化测试 | 101 passed（纯逻辑 / 真实 SQLite / 界面 widget / Markdown 渲染 / 布局 / 日志 / 性能） |
| 静态检查 | `flutter analyze` 0 issue |
| 千篇性能 | 列表 50ms、标题搜索 3ms、正文全表 37ms；首屏仅构建 6 个列表项 |
| 已知限制 | 剪贴板粘贴截图未做；无同步与加密；未签名 —— 详见 `发布说明.md` |

## 6. 本版修过的真实缺陷（供你复测时特别留意）

| 缺陷 | 复测方法 |
|---|---|
| 关窗丢最后 0.8 秒输入 | 输入后立刻点 × 关窗，重开检查 |
| 标题含双引号导出再导入被改写 | 标题写 `读了《人类简史》"第一部分"`，导出再导入 |
| 导入会读取目录外文件 | 导入含 `![](../x.png)` 的目录，不应把外部文件吞进附件库 |
| 写库失败静默丢稿 | 手动把数据库设为只读后再输入，应提示失败且可重试 |
| 窄窗口布局溢出 | 窗口拖到 640×520，工具栏按钮应换行而非被裁掉 |
