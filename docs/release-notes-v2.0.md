# MDiary v2.0.0 发布说明（Windows x64）

发布日期：2026-11-06　｜　版本：`2.0.0+4`　｜　基于 v1.1.1

## 1. 这一版的核心：RAG（本地优先）

日记不再只是"写和看"，还可以**问**：

- 索引：按标题/段落切片（代码块不切），每条带 `entry_id`/日期/标签；
  **附件一起索引**（文件名、类型、大小、所属日记；文本类附件抽正文，图片只存元数据）；
- 检索：向量（bge-m3，1024 维）+ 关键词，RRF 融合；
- 问答：流式回答，**每条事实带 `[日期-标题]` 引用**，点来源回原文；
- 每日语义管理：给新增/修改的日记写摘要 + 标签建议（只建议，不改你的标签）；
- 日报：`rag/reports/YYYY-MM-DD.md`，**空日也写**「这一天没有写日记」，启动补齐到昨天；
- `soul.md`：把整个库归纳成 ≤ 8 KB 的七节档案，可直接贴给任何大模型当上下文；
- RAG 独立界面：导航栏 ✦ 入口，三页签「问答 / 日报 / 档案」。

## 2. 模型可配置（本地 / 云端）

设置 → RAG 模型：

| 项 | 说明 | 默认 |
|---|---|---|
| 交互模型 | 问答（流式） | `qwen3:8b` |
| 生成模型 | 摘要 / 日报 / soul | `qwen3:8b` |
| 向量模型 | 切片 embedding | `bge-m3` |
| Ollama 地址 | 本机服务 | `http://127.0.0.1:11434` |
| 云端开关 | OpenAI 兼容，需显式开启 | 关 |

- 设置存在 `<数据目录>/settings.json`，全局生效；
- 云端 API Key 用 **Windows DPAPI** 加密，只有当前用户能解开；
- **向量索引永远在本地**，云端只用于问答与生成；关掉开关立即停止上送。

## 3. 实测数据（本机：i7-9750H / 16 GB / GTX 1660 Ti 6 GB）

| 项目 | 结果 |
|---|---|
| qwen3:8b 输出 | 约 **10.5 tok/s**（30% CPU + 70% GPU），256 token ≈ 25 s |
| 问答首 token（热） | **0.15 s**，整段约 5.4 s |
| bge-m3 embedding | 100% GPU，300 字切片约 **5.5 条/秒** |
| 首次全量索引 1000 切片 | 约 3 分钟 |

> 重要：qwen3 的思考模式在问答场景又慢又容易答错（27.5 s 且答"没有提到"），
> 已在问答/摘要里默认关闭（`think: false`）。

## 4. 升级说明（v1.x → v2.0）

- 日记数据**自动迁移**（还是 `MDiaryData/db/mdiary.sqlite`），无需手动操作；
- 首次启动会在 `MDiaryData/rag/` 下建索引与目录；
- 没有装 Ollama 也能正常写日记，只是问答/摘要/日报可用性受限（会提示）；
- 备份仍是一份 `mdiary.sqlite` + `rag/reports/` 与 `rag/soul.md`。

## 5. 已知限制

- 问答没有多轮记忆，每次独立；
- embedding 只支持本地（云端只用于问答/生成）；
- 日报/摘要质量取决于本地模型，7B 以下效果一般；
- 窗口位置记忆、导出附件可读名等 v1.1.1 的能力保持不变；
- 安装包未签名，首次运行可能触发 SmartScreen。
