## 1. 升级要点（v1.0 → v1.1）

- **数据库单独放 `MDiaryData\db\`**：升级后首次启动会把根目录的 `mdiary.sqlite`（含 `-wal`/`-shm`）自动移进去。
- **附件字节进数据库**（schema v2，`attachment_blobs` 按 sha256 去重）：
  单文件上限从 25 MB 提到 **100 MB**；`MDiaryData\attachments\` 只作为预览/打开缓存，删掉会自动重建。
  升级时启动阶段会把旧的磁盘附件自动回填进库（幂等，失败会写日志）。
- **导出不变**：仍按原文件形式写 `assets/<sha>.<ext>`，每篇 `.md` 都带引用。
- **备份变简单**：复制 `MDiaryData\db\mdiary.sqlite` 即可（附件都在里面）。

## 2. 新增功能

| 功能 | 说明 |
|---|---|
| 多库 / 换库 | 一个目录 = 一个库（可自定义目录名，如 `库-张三`）；设置 → 数据 →「切换 / 新建库」 |
| 导入新库 | 选一个 `.sqlite`/`.db`，复制到 `MDiaryData\libraries\<名字>\` 并切换 |
| 合并库 | 按日记 id 合并：同 id 保留 `updated_at` 较新的；附件按 sha 去重、标签按名字合并；源库不动 |
| 粘贴截图 | Windows：工具栏「粘贴截图」或 `Ctrl+Shift+V`（GDI+ 读剪贴板，存成 `截图-<时间>.png`） |
| 左栏日历 | 点某天打开/新建当天日记，有日记的日期带圆点，默认停在最新一天 |
| 星图 | 全部 / 年 / 月 / 周 查看所有 .md 与索引的附件，共用附件一颗星连线；点星可查看编辑 |
| 标签 | 编辑器里打标签，列表可见，搜索可命中；导出写 front matter `tags:`，导入读回 |
| 拖拽导入附件 | 从资源管理器把文件拖进窗口（原生 `WM_DROPFILES`，不引插件） |
| 附件名可点 | 正文写 `![西湖.png](assets/<sha>.png)`，预览里名字是彩色标签，点一下用默认程序打开 |

## 3. 修复与体验（来自 v1.0 遗留清单）

- **单实例互斥**：重复启动会激活已有窗口并退出，避免双开互相覆盖。
- **打开附件改用 `ShellExecuteW`**：不再经过 `cmd /c start`，用户名/文件名带 `&`、`%`、引号也安全。
- **导出已删除的日记会报错**，不再写出"幽灵文件"。
- **导入 `.md` 单文件上限 10 MB**，超限写入导入错误清单。
- **回收站支持「清空」**（批量彻底删除 + 附件 GC）。
- **最小窗口尺寸 720×520**（按 DPI 缩放），防止缩到点不到标题栏。

## 5. 已知限制（与 v1.0 相同或已登记）

- 无账号 / 同步 / 加密；无富文本；无 Web 端。
- 检索仍是 `LIKE` 子串（标题 / 正文 / 标签），千篇实测 < 50ms，暂不上 FTS5。
- 截图粘贴仅 Windows（依赖 runner 的 GDI+ 实现）。
- 窗口位置/尺寸不记忆（v1.2 候选）。
- 安装包未做代码签名，首次运行可能触发 SmartScreen。
