# Agent 设置（v2.7.1）

> 管的是内置的两个 agent：分词导入、记忆对话。配置存 `<数据目录>/agents.json`，日志按库存。

## 配置

| 项 | 说明 | 默认 |
|---|---|---|
| 步数上限 | 分词解析失败重试次数；记忆对话固定 1 步 | 3（1–10） |
| 读取文件夹 | 允许分词读取 `.md/.txt` | 开 |
| 新建库 | 允许分词确认后建库 | 开 |
| 写入日记 | 允许把切分结果写进库 | 开 |
| 读取 skill | 允许记忆对话读蒸馏 skill | 开 |
| 检索日记 | 预留（当前记忆只用 skill） | 关 |
| 记录运行日志 | 写 `<库>/agent/runs.jsonl` | 开 |

权限关闭后，对应操作直接报错（不会偷偷跳过）。

## 运行日志

```
<库>/agent/runs.jsonl
{"kind":"segment","at":"...","steps":2,"ok":true,"message":"切出 5 天"}
```

- `segment`：分词（steps = 实际模型调用次数）；
- `memory`：记忆对话（steps = 1）；
- 页面里倒序显示最近 100 条，可一键清空。

## 限制

- 不是通用工具循环：分词/记忆各是一条固定链路；
- 日志不记录 prompt / 日记正文（只记结果摘要）；
- 权限只作用于内置 agent，不影响 RAG 问答。
