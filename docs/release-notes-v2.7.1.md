# MDiary v2.7.1 发布说明（Windows x64）

发布日期：2026-11-10　｜　版本：`2.7.1+14`　｜　基于 v2.7.0

## 1. 模型设置收拢

- 设置页旧「RAG 模型」卡片已删除模型/地址/Key 编辑，只剩「隐私与云端」：
  云端开关、当前云端配置提示、测试连接；
- 所有模型配置（含云端 Key）统一在「模型」里，Key 只存一份（DPAPI 密文）。

## 2. Agent 设置页

导航栏「Agent 设置」：

- **步数上限**：分词解析失败时的最大重试次数（1–10，默认 3）；
- **工具权限**：读取文件夹 / 新建库 / 写入日记 / 读取 skill / 检索日记（预留）；
- **运行日志**：分词、记忆对话每次运行都记 `kind / 时间 / 步数 / 是否成功 / 说明`，存
  `<库>/agent/runs.jsonl`，可清空；
- 权限关闭后对应操作直接拒绝并提示。
