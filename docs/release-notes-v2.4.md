# MDiary v2.4.0 发布说明（Windows x64）

发布日期：2026-11-09　｜　版本：`2.4.0+9`　｜　基于 v2.3.1

## 1. 问答页变成"直接对话"

以前要先点「检索」，再点「生成回答」。现在只有一个输入框：

1. 输入问题 → 点「发送」；
2. 先显示「正在检索…」——系统自动做向量 + 关键词混合检索；
3. 然后逐字流式回答，带 `[日期-标题]` 引用；
4. 回答气泡下面列出本轮来源（日期 + 标题），点一下回到原文；
5. 可以继续追问，最多带最近 6 轮上下文。

## 2. 模型先检索、再回答

多轮追问时，追问往往不能单独检索（「那天气呢？」没有主语）。所以每轮先让**交互模型**把追问
改写成 1–3 条独立检索词（只允许输出 `{"queries":[...]}`），再对每条检索、按片段去重取最高分，
最后把命中的片段 + 上下文一起交给模型回答。

- 改写失败（模型报错、返回不是 JSON、或没有上文）自动退回原问题，不阻塞回答；
- 界面上会显示本轮实际使用的检索词，便于判断检索是否跑偏；
- 事实仍只允许来自检索片段，提示词写死「没有依据就说没有提到」。

## 3. 升级与兼容

- 从 v2.3.1 覆盖安装即可，数据/索引/skill 全部沿用；
- 旧的「检索 + 生成回答」按钮移除，功能合并进对话；
- 云端与本地模型都支持；云端模式下检索词改写与回答各一次请求。
