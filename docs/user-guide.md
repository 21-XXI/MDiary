# MDiary 使用说明（v1.0 Windows）

## 1. 安装与启动

1. 解压 `MDiary-1.0.0-windows-x64.zip` 到任意目录（**整个目录一起移动**，`mdiary.exe` 依赖同级的
   `data\`、`flutter_windows.dll`、`sqlite3.dll`）。
2. 双击 `mdiary.exe`。首次运行 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」
   （安装包未做代码签名）。
3. 程序不写注册表、不装服务；删除目录即可卸载（数据另存，见第 4 节）。

## 2. 界面与操作

| 区域 | 功能 |
|---|---|
| 左上「新建日记」 | 创建一条当天日记（Ctrl+N） |
| 搜索框 | 按标题或正文的中文/英文子串实时过滤（Ctrl+F 聚焦，Esc 退出） |
| 左栏列表 | 按日期分组，置顶项在最前；悬停右侧「…」或右键可置顶/导出/删除 |
| 右栏编辑器 | 第一行标题（可留空），下方正文；右上切「编辑 / 分栏 / 预览」 |
| 工具栏 | 附件、导出 .md、置顶、删除 |
| 底部状态栏 | 篇数、保存状态、版本号 |
| 齿轮 → 设置 | 主题、字号、数据目录、整库导出/导入、清理孤儿附件 |
| 垃圾桶 → 回收站 | 恢复或彻底删除（彻底删除会一并回收附件） |

**自动保存**：停止输入约 0.8 秒即写入本地数据库；切走、窗口失焦、Ctrl+S 也会立即保存。
关闭程序再打开内容仍在。

## 3. 附件

- 点回形针选择文件（单文件 ≤ 25 MB）。图片会直接显示在预览中，其他文件显示为附件卡片，点击用系统默认程序打开。
- 同一文件插入多次只存一份（按内容哈希去重）。
- 附件随日记保存，删除日记进回收站时附件保留；彻底删除后才回收。

## 4. 数据与备份

| 内容 | 位置 |
|---|---|
| 数据库 | `MDiaryData\mdiary.sqlite`（默认在 mdiary.exe 同目录） |
| 附件 | `MDiaryData\attachments\` |
| 设置 | 同目录数据库内 `app_meta` 表 |

- **换位置**：设置 → 数据 → 「更改数据目录」，在资源管理器里选个文件夹。
  数据库与附件会复制过去并逐文件校验，校验通过后旧目录被删除、程序继续用新位置（重启也记得）。
- **备份**：关闭程序后复制整个数据目录（`MDiaryData\`）即可；程序可以整个目录拷到别的电脑上用。
- **迁移/长期归档**：设置 → 整库导出，得到「每篇一个 .md + `assets\` 附件」的普通目录，
  可用 Typora / VS Code / Obsidian 直接打开。
- **导入**：设置 → 从目录导入 .md，递归扫描；同一天且正文相同的条目自动跳过，重复导入不会产生副本。

## 5. 快捷键

| 快捷键 | 功能 |
|---|---|
| Ctrl+N | 新建日记 |
| Ctrl+S | 立即保存 |
| Ctrl+F | 聚焦搜索框 |
| Esc | 退出搜索框 |

## 6. 常见问题

**Q：双击没反应 / 报缺少 DLL？**
必须保留解压后的目录结构，只复制 `mdiary.exe` 单独运行会失败。

**Q：数据想放到别的盘？**
启动前置环境变量 `MDIARY_HOME=D:\我的日记` 即可（便携模式，适合放 U 盘）。
在命令行里：`set MDIARY_HOME=D:\我的日记 && mdiary.exe`。

**Q：回收站里的条目会一直占空间吗？**
会占数据库记录，但附件只有在「彻底删除」后才回收。设置页的「清理孤儿附件」可手动清理无引用文件。

**Q：中文输入法下光标异常？**
v1.0 使用系统原生输入法；若遇到组词异常，请记录现象（输入内容、操作步骤）反馈，这是已知高风险项。

**Q：搜索不到刚写的内容？**
搜索是 250ms 防抖 + 子串匹配，输入完稍等即可；若仍未命中，确认关键词中间没有多余空格。
