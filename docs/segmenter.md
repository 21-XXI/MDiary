# 分词导入（v2.7 第二步）

> 选一个文件夹 → 模型按日期切分成日记 → 预览 → 确认后**自动新建库**并导入。

## 流程

1. 首页工具栏「分词导入」；
2. 选文件夹（递归读 `.md` / `.txt`，单文件 ≤ 2 MB，最多 200 个）；
3. 点「开始分词」，用 **`segment` 角色**的模型（本地 Ollama 或云端）切分；
4. 预览：每天一条（日期、标题、字数、标签、附件数）+ 警告（日期缺失、重复、附件不存在）；
5. 「确认导入」：
   - 在 `<数据目录>/libraries/<文件夹名>/` 新建库；
   - 把结果写成 `<日期>/当期.md`（front matter: title/date/tags）+ 附件；
   - 用现有 Markdown 导入管线导入（附件自动进内容寻址库）；
   - 切换到新库，提示导入/跳过数量。

## 模型输出约定

```json
{"days":[{"date":"2026-11-06","title":"杭州","body":"第一人称正文",
          "tags":["旅行"],"attachments":["西湖.png"]}]}
```

- 只接受 `YYYY-MM-DD`；
- 同一天多段材料应合并（提示词要求）；
- `attachments` 只填资料里出现过的文件名，找不到会丢弃并警告；
- 解析失败直接报错，不产生半成品库。

## 提示词要点

- 只依据材料，不编造日期/金额/人名；
- 同一天合并、第一人称、保留具体名词；
- 输出严格 JSON，不要解释。

## 限制

- 只支持 `.md` / `.txt`；PDF/Word 未做；
- 长资料会按 60k 字符截断（超出部分不参与切分）；
- 模型质量决定切分质量；本地 8B 在长材料上可能漏日期，建议云端或更大模型；
- 预览暂不支持逐条编辑/勾选，只能整体确认或重来；
- 新库名默认文件夹名，可改；重名自动加 `(2)`。
