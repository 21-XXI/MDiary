# MDiary v2.2.0 发布说明（Windows x64）

发布日期：2026-11-06　｜　版本：`2.2.0+6`　｜　基于 v2.1.0

## 1. 新功能：蒸馏 skill

把一个人的日记库压成一份**其他模型可以直接加载的 skill**：

- 输入：`rag/soul.md` + 索引里的语料摘要（最近 80 篇）+ 标签统计；
- 处理：交给**云端大模型**按固定结构蒸馏；
- 产物：`<库目录>/db/skill/<时间>/SKILL.md` + `meta.json`；
- **每次生成新目录，从不覆盖**旧 skill；
- 导航栏新增 **✳ 蒸馏** 入口，页面内有「启用蒸馏」开关；关闭时不出请求。

生成的 `SKILL.md` 包含：何时使用、这个人的画像、常用事实与偏好、检索与回答规则、禁止事项，
开头带 YAML front matter（模型、时间、来源、soul 大小），便于其他 agent 直接加载。

## 2. 前置条件

- 设置 → RAG 模型 → 开启「使用云端模型」并填 API Key（DPAPI 加密保存）；
- 没有 cloud 配置时，蒸馏按钮置灰并提示；
- 没有 `soul.md` 时会先自动生成一次灵魂档案再蒸馏。

## 3. 升级与验证

- 从 2.1.0 升级：`settings.json` 多一个 `skill_enabled`（默认 false），其余不变；
- 质量门槛：`flutter analyze` 0 issue、`flutter test` 236 passed、release 构建成功；
- 新增 8 个测试：生成落盘/不覆盖/同秒去重/缺 soul 报错/16 KB 截断、开关持久化、界面流程。
