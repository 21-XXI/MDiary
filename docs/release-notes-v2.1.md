# MDiary v2.1.0 发布说明（Windows x64）

发布日期：2026-11-06　｜　版本：`2.1.0+5`　｜　基于 v2.0.0

v2.1 是 RAG 的**体验补丁**，不引入新的数据格式，升级无迁移风险。

## 1. 问答可追问

- 同一个问答会话里保留**最近 3 轮**上下文，可以直接问「那晚饭吃了什么？」这类指代问题；
- 回答卡片右上角有「新对话」，一键清空上下文；
- 上下文只影响措辞与指代，事实仍只能来自当次检索到的日记片段（提示词里写死）。

## 2. 回答标注模型来源

回答标题旁显示 `本地 qwen3:8b` 或 `云端 gpt-4o-mini`，一眼能看出这次是否把内容发到了云端。

## 3. 索引状态可见

问答页顶部显示：`索引：128 个切片 · 向量 ollama:bge-m3 · 更新于 2026-11-06 10:12`；
没有索引时提示「点右上角重建索引」。

「重建索引」时显示进度条（已处理 / 总数），不再只有一句 SnackBar。

## 4. 模型支持自定义输入

设置 → RAG 模型的下拉里新增「＋ 自定义…」：可以填 Ollama 里还没拉过、或云端自定义的模型名，
不必等检测列表里出现。

## 5. 升级与验证

- 从 2.0.0 升级：`settings.json` / `rag/` / `soul.md` 全部沿用，无需操作；
- 质量门槛：`flutter analyze` 0 issue、`flutter test` 230 passed、release 构建成功；
- 实测：多轮追问沿用 qwen3:8b 热态 5–6 秒/次；索引状态与进度、云端/本地标注均在界面测试覆盖。
