# 参考资料：MDiary 导入格式

## 目录结构

```
任意父文件夹/
  2026-11-06/
    当期.md        # 文件名任意，建议 当期.md 或日期.md
    西湖.png       # 附件，放同目录
    发票.pdf
  2026-11-07/
    当期.md
```

- 日期文件夹支持：`2026-11-06`、`2026.11.06`、`2026_11_06`、`2026年11月6日`、`20261106`；
- 导入时递归扫描所有 `.md`，**日期文件夹名优先于文件修改时间**；
- 文件里写了 front matter 的 `date` 时以 front matter 为准。

## front matter

```yaml
---
title: 标题（可省略，省略时用文件名）
date: 2026-11-06
tags: [旅行, 工作]
---
```

- `date` 格式 `YYYY-MM-DD`；
- `tags` 支持 `[a, b]` 或 `- a` 列表；
- 没有 front matter 也能导入：标题取文件名，日期取文件夹名（没有日期文件夹则取修改时间）。

## 附件

- 正文引用：`![说明](西湖.png)` 或 `[发票.pdf](发票.pdf)`；
- 导入时引用到的文件会复制进附件库（按内容哈希去重），正文引用改写成 `assets/<sha>.<ext>`；
- **日期文件夹里没有被引用的文件**也会作为附件导入，并在正文末尾追加：

  ```markdown
  ## 附件

  - [西湖.png](assets/<sha>.png)
  ```

- 单个附件上限 100 MB；
- 只导入导入目录内部的文件，`../` 或绝对路径不复制。

## 重复导入

- 标题 + 正文 + 日期相同视为重复，跳过；
- 想重新导入请在 MDiary 里删掉旧条目，或改一下正文。

## 导出的模样

导入后再整库导出，会得到：

```
<导出目录>/
  2026-11-06-杭州出差第一天.md
  assets/
    西湖-7fee04ef.png
```

附件名变成 `<原名>-<sha8>.<ext>`，仍然保持原文件形式（v1.1.1+）。
