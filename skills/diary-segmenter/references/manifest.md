# manifest.json 格式

`scripts/build_diary.py` 的输入，数组、按日期升序：

```json
[
  {
    "date": "2026-11-06",
    "title": "杭州出差第一天",
    "tags": ["旅行", "工作"],
    "body": "今天到了杭州，风很大……\n\n晚上吃了片儿川，回酒店把发票塞进包里。",
    "attachments": ["C:/素材/西湖.png", "C:/素材/发票.pdf"]
  },
  {
    "date": "2026-11-07",
    "title": "开会",
    "tags": ["工作"],
    "body": "上午开会，下午改签车票提前回家。"
  }
]
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `date` | 是 | `YYYY-MM-DD`，同时作为文件夹名 |
| `title` | 否 | 省略时用日期 |
| `tags` | 否 | 字符串数组，写进 front matter |
| `body` | 是 | 第一人称正文；附件用相对文件名引用 |
| `attachments` | 否 | 绝对或相对路径；会复制到对应日期文件夹，文件名保持原样 |

规则：

- `body` 里引用附件写 `![说明](文件名)`，文件名必须和复制后的文件名一致；
- 没在正文引用的附件也会被 MDiary 导入（日期文件夹特性）；
- 同一天只能有一条；同一天多段材料请在生成 JSON 前合并。
