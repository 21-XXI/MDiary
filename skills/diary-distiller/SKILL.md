# SKILL: mdiary-distiller

> 把一个人的日记库（主文件 + 附加笔记 + soul.md）蒸馏成一份可加载的 skill。

## 输入

- `soul.md`（灵魂档案，≤ 8 KB）；
- 主文件摘要（`entry_summary`，没有就用正文首行）；
- **附加笔记**（`notes/*.md`）的正文/摘要，作为细节来源。

## 输出结构（固定）

```markdown
# Skill: <一句话名字>
> <一句话说明>
## 何时使用
## 这个人的画像
## 常用事实与偏好
## 检索与回答规则
## 禁止事项
## 资料分层
```

`资料分层` 一节固定三块：

- **主文件事实**：来自日期主 `.md` 的稳定事实（时间、地点、金额）；
- **附加笔记细节**：来自 `notes/*.md` 的展开细节，标注文件名；
- **不确定项**：材料里没有写清的，写「不确定」。

## 规则

1. 每条事实后面标注来源：`[主 2026-11-06]` 或 `[附 详细行程.md]`；
2. 附加笔记只能补充细节，不能推翻主文件事实；
3. 不编造日期、金额、人名；不确定就写不确定；
4. 只输出 Markdown，不要解释；
5. 总长度 ≤ 6000 字。

## 来源标注示例

```markdown
- 2026-11-06 去杭州出差，住宿 380 元 [主 2026-11-06]
- 当天晚上吃了片儿川，排队 20 分钟 [附 详细行程.md]
```
